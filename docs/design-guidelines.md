# SASA 공강맵 디자인 가이드라인

이 문서는 현재 리디자인 기준이다. 화면 구조나 디자인 방향이 바뀌면 함께 갱신한다.

## 핵심 목적

학생이 가장 먼저 필요한 정보는 "지금 어느 교실이 비어 있는가"다. 첫 화면은 기능 나열보다 현재 교시, 빈 교실 수, 실제 지도, 선택 교실 설명을 우선한다.

## 정보 구조

- 모바일 주요 탭은 지도, 검색, 소셜, 일정 4개로 유지한다.
- 지도 상단의 빈 교실 수, 일정 상단의 공강 수처럼 중복 숫자 요약은 기본 노출하지 않는다.
- 검색은 별도 탭이다. 검색 결과를 누르면 상세 팝업을 먼저 보여주고, 필요할 때만 `지도에서 보기`로 이동한다.
- 소셜은 친구 위치와 친구 추가를 분리한다. 소셜 화면에는 지도 연결 버튼을 두지 않는다.
- 일정은 월화수목금 선택 후 해당 요일의 10개 막대(1~4교시, 점심, 5~9교시)를 보여준다.
- 공강실 예약은 일정이 아니라 지도 교실 정보 패널에서 처리한다.
- 관리자 화면은 데스크탑 중심으로 별도 레이아웃을 쓴다.
- 관리자 탭은 예전 기능을 유지한다. 사용자 권한 변경, 수업 데이터 추가/수정/삭제/엑셀 업로드/내보내기, 교실 추가/수정/삭제/상태 변경이 가능해야 한다.

## 모바일 원칙

- 모바일은 상단에 로고, 다크모드, 도움말, 프로필만 둔다.
- 로그아웃은 모바일 상단에 직접 노출하지 않고 프로필 팝업 안에 둔다.
- 하단 탭은 지도, 검색, 소셜, 일정만 둔다.
- 화면 높이를 강제로 채우지 않는다. 내용이 적으면 자연 높이로 끝나고, 넘치면 스크롤한다.
- 텍스트가 버튼이나 막대 안에서 줄바꿈되어 어색해지지 않도록 말줄임과 짧은 라벨을 우선한다.

## 지도

- 실제 서비스 지도는 기존 SVG/이미지 기반 지도를 유지한다. 프로토타입 지도는 임시 지도다.
- 지도 내부에는 호실명 중심으로 표시한다. 상태 설명은 지도 아래 선택 교실 패널에서 처리한다.
- 선택 교실 패널에는 교실명, 상태, 설명만 둔다.
- 선택 교실 패널 하단에는 공강실 예약 영역을 둔다. 월~일, 1~9교시를 선택하고 `사용하기`로 신청한다.
- 예약 취소는 선택 교실 패널의 공강실 예약 영역 아래 `내 예약` 목록에서 처리한다.
- 공강실 예약은 독점 점유가 아니므로 여러 사용자가 같은 교실/교시에 중복 신청할 수 있어야 한다.
- 승인 필요, 사용 불가, 점검 중인 교실에는 공강실 예약 UI를 보여주지 않는다.
- 현재 수업 중인 교실이라도 다른 교시에 비어 있으면 공강실 예약 UI를 보여준다.
- 공강실 예약 교시 목록에는 해당 교실에 정규 수업이 없는 빈 교시만 보여준다.
- 검색에서 지도 이동 시 해당 층으로 이동하고 해당 교실을 선택한다.
- 지도 좌상단에는 색상 범례를 둔다.
- 색상 범례에는 승인 필요 상태도 포함한다.
- 지도는 마우스 휠, 트랙패드 스크롤, 모바일 핀치로 확대/축소할 수 있어야 한다.
- 지도 아래 교실 정보 패널은 남은 화면 안에 들어오도록 컴팩트하게 유지한다.
- 지도 아래 교실 정보 패널은 모바일 하단 탭을 침범하지 않아야 한다.

## 검색

- 검색창 앞에는 돋보기 아이콘을 둔다.
- 플레이스홀더는 `찾고 싶은 정보 검색`을 쓴다.
- 결과 항목은 교실/과목/교사 유형 칩과 제목, 요약만 보여준다.
- 상세 정보와 지도 이동은 팝업에서 처리한다.

## 일정

- 공강 막대의 보조 문구는 `시간표 추가하기`다.
- 점심 막대는 `점심`과 시간만 보여준다. `점심시간`을 반복하지 않는다.
- 점심 막대 높이는 다른 교시 막대와 동일하게 유지한다.
- 교시별 과목 설명은 과목명 아래에 교실 또는 선생님 이름을 작게 둔다.
- 현재 교시는 초록색 점으로 표시한다.
- 막대를 누르면 기존 기능처럼 학교 수업 선택 또는 직접 입력으로 수정할 수 있다.
- 시간표 수정 UI는 원래 사이트의 모달 구조를 유지한다. 학교 수업 선택 목록, 검색, 직접 입력, 삭제/취소/저장 액션을 한 화면에 둔다.
- 1~9교시가 한눈에 들어오도록 막대 높이와 간격은 조밀하게 유지한다.
- 모바일 시간표 막대는 남은 화면 높이에 맞춰 유동적으로 늘거나 줄어 하단 탭 바로 위에서 끝나게 한다.
- 시간표 스크롤 박스는 내부 막대 목록보다 작게 렌더링되어 막대가 밖으로 삐져나오지 않아야 한다.
- 시간표 막대 안 텍스트는 말줄임으로 처리하고 블럭 외부로 벗어나지 않아야 한다.
- 일정 화면의 세로 스크롤은 페이지 전체가 아니라 시간표 블럭 내부에서 일어나도록 한다.
- 시간표 블럭도 모바일 하단 탭을 침범하지 않아야 한다.

## 색과 대비

- 기존 사이트의 밝고 실용적인 느낌은 유지한다.
- 모든 요소가 비슷한 존재감을 갖지 않도록 primary action과 현재 상태에만 강한 색을 쓴다.
- 상태 색상은 유지한다: 빈 교실 초록, 수업 노랑, 사용 중 빨강, 사용 불가 회색.
- 다크모드는 단순 색반전이 아니라 낮은 대비의 어두운 배경, 부드러운 표면색, 선명한 텍스트를 쓴다.

## 아이콘

- 기존 SASA 로고는 유지한다.
- 기능 아이콘은 lucide 기반으로 통일한다.
- 아이콘은 보조 인지 수단이다. 핵심 라벨을 대체하지 않는다.
